# Data

The raw workbook is **not included**: the repository record marks it as protected by original copyright.

1. Open https://doi.org/10.17877/DE290R-23085 (TU Dortmund, Eldorado repository).
2. Download `20230131_PunchingShearDataRev1-Spyridis.xlsx` (57.94 kB).
3. Save it as `data/raw/20230131_PunchingShearDataRev1-Spyridis.xlsx`.

The loader checks the SHA-256 checksum of the version analysed here:
`6bf3c6f6b380b8fc560de50c07bbb3f6db25389f85571d5129b478b1d10f41bb`.
If the repository publishes a newer revision, the loader will refuse it until the cleaning rules are reviewed.

Column definitions, units and every cleaning decision are in [`DATA_DICTIONARY.md`](DATA_DICTIONARY.md).

Please cite the dataset (Spyridis, Mellios, Uz & Walter, 2023) and the related paper
(Mellios, Uz & Spyridis, 2023, *Engineering Structures* 275, 115195) when using it.
